# Online Sales Cockpit

Tracking-Tool für freiberufliche Online-Sales-Berater: Auftraggeber, Calls, Abschlüsse, Provision.
Eine einzige HTML-Datei, kein Server, keine Datenbank. Die Daten bleiben im Browser bzw. in der eigenen Datei des Nutzers.
